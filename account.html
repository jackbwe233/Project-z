What an account does

Create an email-based identity for Z and sign in or out securely. Your account password and email verification are handled by the authentication provider.

Optional cloud backup. You can upload and restore My Day, music, and paper data manually after enabling secure database access. Conversations and notes are not automatically syna between devices. We won't silently upload them when you sign in.

Z can be used without an account. Don't put passwords, banking information, or other sensitive details in your profile or chats.

For the Z owner: turn on account registration
  1. Create a project at Supabase and open your project's API settings.
  2. Copy the Project URL and the publishable key (or legacy anon key). These two values are designed to be public.
  3. In Z's z-auth-config.js, set url and publishableKey to those values; commit the change.
  4. In Supabase → Authentication → URL Configuration, set the Site URL to https://jackbwe233.github.io/Project-z/ and add https://jackbwe233.github.io/Project-z/account.html to allowed Redirect URLs.
  5. Enable Email authentication and keep email confirmation turned on. Configure an email sender before wider public use.
  6. Test sign-up, magic-link login, and sign-out yourself before inviting other people.

Never put the Supabase service_role or secret API key in GitHub or your website. This static app does not have an authenticated backend for private database access.

If you're launching Z for other people, publish appropriate terms and privacy details first. Email delivery, account security and user deletion requests are the app owner's responsibility.
